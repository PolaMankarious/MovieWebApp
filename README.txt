CINESCOPE — MOVIE REVIEW WEBSITE
Web Engineering Project — Phase 1

WHAT IS INCLUDED
- index.html: guest landing page
- movies.html: movie catalog and search form
- movie-details.html: sample movie details and reviews
- login.html: login form
- signup.html: registration form with account type field
- submit-review.html: review and rating form
- my-reviews.html: submitted reviews and statuses
- admin-dashboard.html: admin dashboard
- add-movie.html: add movie form
- edit-movie.html: edit movie form
- manage-reviews.html: accept/reject review interface
- css/style.css: external stylesheet shared by all pages
- COVER_PAGE_TEMPLATE.txt: cover page details to complete before submission

IMPORTANT PHASE 1 NOTES
- Built using plain HTML and CSS; no frameworks.
- Movie/review lists are static sample content as allowed by the assignment.
- Forms use HTML fields and native validation, but they do not save data.
- Search, authentication, CRUD, approval/rejection and messages are visual/static prototypes only.
- For the next phase, these pages can be connected to dynamic data and application logic.
- Update all team details in the cover page template before submission.

HOW TO RUN
1. Extract the ZIP.
2. Open the Movie_Review_Website_Phase1 folder in VS Code.
3. Open index.html in a browser (double-click it or use Live Server if installed).
4. Use the navigation links to visit the other pages.
